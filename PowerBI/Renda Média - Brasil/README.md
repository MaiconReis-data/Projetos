Dashboard Renda Média - Brasil


Sobre o Projeto

Este projeto foi desenvolvido em Power BI com o objetivo de analisar a **renda média no Brasil**, disponibilizando uma visão estruturada dos dados para acompanhamento e exploração dos indicadores relacionados à renda.


Objetivos do projeto

- Monitorar indicadores relacionados à renda média.
- Acompanhar a evolução e o comportamento da renda.
- Permitir análises comparativas dos dados de renda.
- Identificar tendências e pontos de atenção.
- Apoiar a tomada de decisão baseada em dados.


Estrutura do Projeto

- `Renda Média - Brasil.pbix` — Arquivo principal do dashboard Power BI.


Principais Indicadores

- Renda média
- Análise da renda por período
- Comparações relacionadas à renda
- Distribuição e evolução dos indicadores de renda


Tecnologias Utilizadas

- Power BI
- Power Query
- DAX


Como Utilizar

1. Abra o arquivo `.pbix` no Power BI Desktop.
2. Atualize as fontes de dados, se necessário.
3. Navegue pelas páginas do relatório para explorar os indicadores.
