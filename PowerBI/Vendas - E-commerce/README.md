Dashboard Vendas E-commerce


Sobre o Projeto

Este projeto foi desenvolvido em Power BI com o objetivo de analisar o faturamento de uma empresa de e-commerce que comercializa produtos de diversa categorias.


Objetivos do projeto

- Monitorar indicadores de vendas.
- Acompanhar faturamento e desempenho comercial.
- Identificar tendências e oportunidades de crescimento.
- Apoiar a tomada de decisão baseada em dados.


Estrutura do Projeto

- `Vendas e-commerce.pbix` — Arquivo principal do dashboard Power BI.


Principais Indicadores

- Receita/Faturamento
- Quantidade de pedidos
- Ticket médio
- Desempenho por período
- Análises por produto, categoria ou canal (quando aplicável)



Tecnologias Utilizadas

- Power BI
- Power Query
- DAX
- Banco de dados PostgreSQL



Como Utilizar

1. Abra o arquivo `.pbix` no Power BI Desktop.
2. Atualize as fontes de dados, se necessário.
3. Navegue pelas páginas do relatório para explorar os indicadores.


O que este projeto demonstra

- Modelagem dimensional
- Transformação de dados com Power Query
- Criação de métricas e KPIs com DAX
- Desenvolvimento de dashboards executivos
- Storytelling com dados
- Análise de desempenho de vendas
